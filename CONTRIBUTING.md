# Contributing

[简体中文](CONTRIBUTING_zh.md). Create a virtual environment and follow README installation. Run `make test`, `make lint`, `make build`. Keep public API explanations and docs/en and docs/zh aligned. Do not change a pruning bound without independent scalar reference tests at equality boundaries. An uncertain summary must scan, never silently drop rows.

Record benchmark changes before measurement, keep every trial including regressions, and regenerate README tables with `python -m segmentlens report`. Use new result names; preserve historical results. Use Conventional Commits. Include provenance when copying any third-party code, preserve its obligations, and do not call an established optimization novel. Keep private files and credentials outside the repository.
