# Upstream analysis

DuckDB addresses in-process analytical queries through columnar storage, vectors, and an execution pipeline. The fixed study snapshot is [`7e1c37c0e96182c8f00843274043a0e7d2f0287e`](https://github.com/duckdb/duckdb/commit/7e1c37c0e96182c8f00843274043a0e7d2f0287e). The live GitHub API audit on 2026-09-21 (Asia/Shanghai) observed 41,601 stars / 3,812 forks. Latest formal release observed: v1.5.5, 2026-07-22. The snapshot includes a 2026-09-21 transaction-revert fix; recent code activity is within 90 days. Stars are a point-in-time observation, not a growth claim.

Read source: [DataChunk](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/src/common/types/data_chunk.cpp), [selection vectors](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/src/include/duckdb/common/types/selection_vector.hpp), [physical filtering](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/src/execution/operator/filter/physical_filter.cpp), [numeric statistics](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/src/storage/statistics/numeric_stats.cpp), and [hash aggregation](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/src/execution/operator/aggregate/physical_hash_aggregate.cpp). `PhysicalFilter::ExecuteInternal` uses `SelectExpression` and slices a chunk; numeric statistics conservatively bound segments. The MIT [license](https://github.com/duckdb/duckdb/blob/7e1c37c0e96182c8f00843274043a0e7d2f0287e/LICENSE) was read, not merely inferred from the GitHub label.

SegmentLens independently implements a bounded subset in Python/NumPy. It does not wrap DuckDB for its core execution. No upstream code or data was copied; all `src/segmentlens/` modules and tests were written for this implementation after source inspection. This is not a strict clean-room claim. DuckDB already performs statistics pruning and has a much richer optimizer. Adding min/max and bounded categorical summaries improves our full-scan B; it is not an invention or a claim that upstream lacks pruning. Optional native DuckDB 1.4.0 is a separately pinned correctness oracle and differs from the source-study snapshot. No upstream runtime speed comparison is made.

NumPy is the only runtime dependency (BSD-3-Clause; its wheel includes separately licensed components). No models, external datasets or visual assets are redistributed. See [third-party manifest](../../THIRD_PARTY.md).
