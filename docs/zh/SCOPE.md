# 范围与预先验收标准

记录于2026-09-21（Asia/Shanghai），先于实现。

SegmentLens 独立实现 DuckDB 风格的小型列式执行子系统：不可变列导入及保存、按批次以选择向量执行合取类型化过滤、分组 count/sum 聚合。固定参考 `duckdb/duckdb@7e1c37c0e96182c8f00843274043a0e7d2f0287e`（MIT），当日核验41,601 Stars、3,812 Forks。非官方实现，不是完整SQL数据库或Fork；未复制上游源码，阅读过源码，不宣称严格clean-room。

B为向量化完整分段扫描；C增加保守数值min/max及有界类别成员摘要，在过滤与聚合前跳过不可能匹配的段。DuckDB已经具备统计剪枝；这是相对本项目B的工程增量，不宣称新算法或超过DuckDB。

预定目标：10,000 / 50,000 / 200,000行有序选择性区间负载，段大小512，各规模过滤求值行数至少减少80%；计数完全相同，sum满足rtol=1e-10、atol=1e-10。一次预热、三次重复、种子20260921、单BLAS线程、交替B/C顺序。公开随机顺序和无选择性查询的不利结果。这是工作量指标，不代表物理磁盘读取或RSS。元数据构建、完整加载与查询分别计时。float64，仅合成数据。

范围边界：有限float64数值、Unicode字符串；不实现SQL解析、join、更新、MVCC、网络服务、NULL语义、并行引擎或数据库事务。表必须放入内存。NPZ禁用pickle，加载全部数据并重建元数据，不声称磁盘跳读。可选DuckDB 1.4.0只作单独固定版本的正确性参考，与源码研究SHA不同，不作性能对比。

验收覆盖参考聚合、非法输入、只读列、保存往返、全部支持谓词的保守剪枝、CLI、原始结果格式、wheel/sdist。宿主机无Docker，本地未验证，CI状态单独记录。
