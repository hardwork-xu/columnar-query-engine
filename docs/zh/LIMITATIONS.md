# 限制

v0.1.0为CPU实验版本，无SQL解析、join、并发修改、事务、崩溃恢复、溢写、分布式或生产部署。无NULL/NaN/Inf。float64求和与顺序有关，容差已说明；极端有限输入可能溢出并报错。不支持绝对值大于2^53的整数。

全部数组内存常驻，NPZ全量加载，摘要和NumPy临时数组占用额外内存。高基数、无序及宽查询可能让C无收益或更慢；类别集合上限256。复制数据和构建元数据有导入开销，已单独计时。

仅小规模合成数据，无真实用户数据或行业基准。DuckDB 1.4.0是单独版本正确性对照，非研究SHA，不作上游计时比较。宿主机无Docker；如实际CI容器任务通过，仅证明Linux CPU路径，不代表Metal/CUDA支持。

NPZ须来自可信来源且大小合理；禁用pickle不能防御压缩包资源耗尽。save拒绝覆盖，但不提供原子数据库事务恢复。只读数组是编程约定，不是恶意代码安全边界。
